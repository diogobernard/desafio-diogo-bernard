=== Capacidade esgotada

Cada instância da API limita as solicitações de emissão em processamento simultâneo
(`nota-fiscal.ingresso.max-simultaneas`). Quando nenhuma vaga é liberada dentro de
`nota-fiscal.ingresso.espera-maxima`, a API responde `503` com `Retry-After` e não
persiste nada. É uma sobrecarga operacional, e não uma regra de negócio: o cliente pode
repetir o pedido com a mesma `Idempotency-Key`, sem risco de duplicidade.
